# Shooter Sam

Shooter Sam is a third-person shooter developed using Unreal Engine 5 and C++ as part of the GameDev.tv Unreal Engine 5 C++ game development course.

The project explores third-person combat, enemy AI, animation workflows, and visual effects while building on the gameplay programming concepts introduced in earlier projects.

## Project Overview

- **Engine:** Unreal Engine 5
- **Language:** C++
- **Genre:** Third-Person Shooter
- **Project Type:** Course-based learning project
- **Course:** Unreal Engine 5 C++ Game Development — GameDev.tv

## Gameplay

The player engages enemies in a third-person environment using shooter mechanics and character animations.

## Learning Objectives

- Implementing gameplay systems with C++
- Working with third-person character controls
- Understanding enemy AI behavior
- Integrating weapon and combat mechanics
- Exploring animation blueprints
- Working with particle effects
- Connecting C++ gameplay classes with Unreal Engine assets

## Technologies

- Unreal Engine 5
- C++
- Unreal Engine Animation Blueprints
- Unreal Engine AI tools
- Visual Studio
